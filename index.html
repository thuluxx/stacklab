      LIFO — Last In, First Out

      A stack is a linear data structure where insertion and deletion both happen at one end called the top. The element added last is the one removed first — exactly like a stack of plates: you always lift the top plate and never pull one from the middle.

      • Push — inserts an element on top of the stack.
      • Pop — removes and returns the top element.
      • Peek (Top) — reads the top element without removing it.

      Time complexity

      Operation Time Why
      Push O(1) Places the value at the top index — no shifting needed.
      Pop O(1) Removes only the top element — nothing to search.
      Peek O(1) Reads one known position: the top.

      Stack overflow happens when you Push at full capacity (8). Stack underflow happens when you Pop or Peek an empty stack.
